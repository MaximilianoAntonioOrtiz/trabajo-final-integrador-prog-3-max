## 🛠️ Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/MaximilianoAntonioOrtiz/trabajo-final-integrador-prog-3-max.git](https://github.com/MaximilianoAntonioOrtiz/trabajo-final-integrador-prog-3-max.git)
   cd trabajo-final-integrador-prog-3-max
   ```

2. **Ejecutar el proyecto**
   ```bash
   npm run dev
   ```
